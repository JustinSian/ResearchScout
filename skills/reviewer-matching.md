# 审稿人匹配 SOP

## 目标

给定一篇稿件（或它的主题），从库里挑出**领域对口、有评审能力、无利益冲突**的候选人。

## 步骤

1. **抽主题**：中文主题词经 `LEX` 映射为英文检索词（语料是英文）。
2. **召回**：researcher 走两条通道 —— 人物 FTS + 论文 FTS → 聚合到作者，
   有深档案的加权（能算指标）。召回 8~20 人。
3. **算指标**：analyst 读档案，取 h-index、全量论文数、近五年产出占比、近五年主题词。
4. **打分**：`得分 = 0.5×主题命中率 + 0.3×归一化 log10(h) + 0.2×近五年产出占比`
5. **校验**：verifier 逐条核对
   - 指标类：h-index / 论文数必须与档案一致
   - 领域类：候选人近五年标题里**至少命中 2 个**稿件主题词
     （只命中 1 个不算：`cancer` 这种词几乎人人都蹭得到）
6. **出报告**：被 verifier 驳回的人不进最终榜单，单独列出并说明原因。

## 已知失效场景

- 同名不同人：h-index 很高但方向完全不符（晶体结构 vs 肺癌）→ 靠领域校验拦。
- 子领域过细：肺移植专家对"肺癌外科"合适、对"肺癌免疫治疗"不合适，
  当前主题词表只有粗粒度，会误杀。
- 候选池只有 102 人（有深档案的），不是全库 8,849 人。

## 变更记录

- v1：只按 h-index 排序 → 出现同名不同人。
- v2：加领域校验（≥2 词命中）+ 主题权重 0.5。
