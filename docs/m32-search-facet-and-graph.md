# M32：检索页 facet + 图谱缩放与国家着色

上一轮把 facet 接进了专家墙和对话，但**检索页**还是纯相关度检索；图谱也只能拖节点，
看不到全局。这一轮补齐两处入口。

## 一、检索页的 facet（保序过滤）

**关键取舍：不重排。** 检索页的排序是 BM25/向量的相关度，如果为了筛选去按被引排序，
"相关度"就被偷偷换成了"影响力"，这是评测里最容易被掩盖的错误。

做法：

```
1. 按相关度多取一批候选（有筛选时取 max(limit*6, 60)）
2. 用 SQL 求出符合条件的 pid 集合
3. 保序过滤，再截 limit 条
```

实测（`q=lung cancer`, `mode=bm25`）：

| 筛选 | 命中 | 第一位 |
|---|---|---|
| 无 | 10 | Minhua Peng |
| `country=CN` | 10 | Yi-Long Wu（吴一龙） |
| `cites_min=10000` | 10 | Hyuna Sung |
| `CN + cites≥10000` | 9 | Yi-Long Wu |

`works` 不受影响（`facets: null`）——筛选只对"人"有意义。

## 二、图谱：缩放、平移、复位

力导向布局仍在"世界坐标"里算，缩放平移只作用于**绘制和命中测试**：

```js
ctx.setTransform(k, 0, 0, k, tx, ty)   // 绘制前
world = ((screen.x - tx) / k, (screen.y - ty) / k)  // 命中测试
```

- 滚轮缩放**跟着鼠标走**（以光标为锚点，不是以中心）；
- 拖空白 = 平移，拖节点 = 拖人（互不冲突）；
- 双击 / 「复位」按钮 = 回到 1:1；
- 换图自动复位，避免新图沿用上一张的缩放。

## 三、图谱：按国家着色

`colorOf()` 增加 `country` 模式：有国家就按国家散列取色，**没有国家的人统一灰色**，
不猜、不按机构名硬推。图例随之切换成"国家（人数）"。

后端配合：

- `graph_neighbors()` 的 people 查询加了 `country`；
- `/graph/path` 的每跳也带 `country`（实测：`Léon Bottou (US) → Yoshua Bengio (CA)`）。

当前国家覆盖率 82%（38,980/47,569），所以图里仍会看到灰点——这是数据现状，不是 bug。

## 四、落地的位置

| 文件 | 改动 |
|---|---|
| `app/api.py` | `/search` 增加 `country/inst_kind/cites_min`（保序过滤，仅 people）；`/graph/path` 带 country |
| `app/search.py` | `graph_neighbors()` 查询补 `country` |
| `web/index.html` | 检索页三个下拉（复用 `/experts/facets` 的国家清单）；图谱滚轮缩放/拖拽平移/复位按钮/国家着色/图例切换 |

## 五、边界与遗留

1. **筛选后可能不足 limit 条**：候选池上限 300，极端条件下会少于 10 条——
   这是"保序"的必然代价，界面会显示"命中 N 条"；
2. **国家缺失的人**在着色上是灰的，占比约 18%；
3. **图谱没有小地图**，缩放到 4× 以上容易迷路（复位按钮可救）；
4. 检索页筛选**不参与排序**，想要"按被引排"仍要回专家墙。
