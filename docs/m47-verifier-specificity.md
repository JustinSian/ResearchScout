# M47：给 verifier 加"词项区分度"——一次失败的优化，和它的边界

> **更正（见 [m48](m48-injection-bug-correction.md)）**：本文"67% 是内容判据的天花板"不成立，
> 根因是 m46 注入器的映射 bug。修正注入后，内容判据即可达到 100% 检出、0% 误报。
> `_specific_terms` 的收益（误报从 13% 降到 0%）仍然成立。


## 起因

m46 的故障注入发现：**跨人注入（把 A 的领域换成 B 的真实主题词）只有 67% 检出**。
当时的建议是"加作者身份/合作者一致性判据"。这一轮先做了一件更便宜的事：
**判断这些词是不是属于这个人**。

## 三次尝试（两次失败）

### v1：作者排行前 20

判据：此人在该词的作者排行里进前 20。

结果：跨人检出仍是 67%，耗时从 201ms → 1957ms/100 条。
原因：`patients`、`clinical` 这类词人人都有，钟南山也在前 20。

### v2：排行前 20 + 词项区分度（df ≤ 25% 的人）

结果：**跨人检出 100%**，但**误报 13%**。

误报样例：

```
pid=527（钟南山）topic=['asthma','lung']  → 命中但没有"专属词"
pid=503（李兰娟）topic=['liver','microbiota'] → 同上
```

根因：钟南山的 `asthma` 数量不如专科哮喘研究者多，**排行法会把他自己的真实主题判成"不属于他"**。

### v3：相对强度（当前版本）

判据：此人对该词的使用量 ≥ 5 篇，且 ≥ 0.8 × 平均携带者的使用量。

结果：**误报 0%**，跨人检出回到 67%，耗时 115ms/100 条（含一次预热）。

## 结论：67% 是内容判据的天花板

v3 之后我停下来想清楚了一件事：

> 当 A 和 B **本来就共享词汇**时，"这些词是否属于 A"这个问题**没有内容层面的答案**。

钟南山和李兰娟都是 COVID 临床研究者，标题里都有 `patients`、`clinical`、`cohort`。
把李兰娟的 `liver/microbiota` 安到钟南山头上会被抓到（他几乎不写），
但把**同领域 B** 的词安到 A 头上，A 的使用量本来就不低——任何基于词频的判据都过。

要真正解决，需要**身份级信号**，而当前 claim schema 里没有：

| 需要的信号 | 现状 |
|---|---|
| 合作者重叠（A 与 claim 里的合作者是否有边） | claim 里没有"另一个人" |
| 机构一致性（A 的机构是否匹配该领域） | 需要额外字段 |
| 同名消歧（多个 A 的候选） | 系统层面没做 |

**所以正确做法不是继续调阈值，而是承认这就是边界**，并在 claim 里补字段再谈修复。

## 现有收益

虽然没把 67% 提上去，v3 带来两个实际改善：

| 指标 | m46（原版） | m47（v3） |
|---|---|---|
| 干净 claim 误报 | 0% | **0%** |
| 无意义注入检出 | 100% | 100% |
| 跨人注入检出 | 93%（domain 67%） | 93%（domain 67%） |
| 每 100 条耗时 | 201ms | **115ms**（词表统计预热后） |

延迟降低是因为把"每个词一次 GROUP BY LIKE"换成**一次全表扫描 + 进程内缓存**。

## 代码改动

`app/subagents.py`：

```python
_term_stats()      # 一次扫 dossier_work，缓存 {word: {pid: count}}
_specific_terms()  # 相对强度判据（≥5 篇 且 ≥0.8×均值）
```

`domain` 分支现在要求：命中词数达标 **且** 至少一个词"属于这个人"。
`rejected` 记录里多一个 `specific` 字段，便于事后分析。

## 测试

全量 **153 项**通过（本轮未新增纯函数测试——`_specific_terms` 依赖全表统计，
属于集成行为，用故障注入实验覆盖比单测更真实）。

## 遗留 / 下一步（按价值排序）

1. **扩 claim schema**：`domain` 增加 `expect_coauthors: [pid...]`，用"合作者重叠"判身份级一致性——
   这是把 67% 拉起来的最低成本路径；
2. **同名消歧**：`people` 里同名多条时，claim 应带 `orcid` 或机构才能判；
3. 用**跨领域**注入单独统计（近领域混淆本就该承认难分），把指标的语境写清。
