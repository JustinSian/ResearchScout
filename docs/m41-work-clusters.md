# M41：论文聚类（研究流派）

## 目标

11k 篇论文按引用关系分堆，回答"这些论文形成了哪些流派"，并给每篇论文标一个"研究社区"。

## 算法选择：先试标签传播，失败了

一开始用标签传播（label propagation）：几行代码、无需依赖。**在玩具图上就翻车了**：

```
两个三角形 + 一条桥边
标签传播 → 1 个社区（把两个团合并了）
```

原因：每个节点取"邻居中出现最多的标签"，桥边让两边互相传染，
小社区被大社区吞掉——这是标签传播的已知缺陷。

换成 **Louvain 局部移动**：只在"模块度增益为正"时移动节点，桥边不足以合并两边。

```
同一张图 → 2 个社区（3 + 3）✓
```

## 结果

```
11104 篇 → 3406 个社区 / 最大 400 篇 / 1.1 秒
```

最大的几个社区（附代表论文）：

| 社区 | 规模 | 代表论文 | 判断 |
|---|---|---|---|
| 24 | 400 | A resource-based view of the firm | 管理学 / 组织行为（成立） |
| 8 | 307 | Global cancer statistics 2018 (GLOBOCAN) | 肿瘤流行病学 + 生信（**混合**） |
| 55 | 300 | Handbook of Social Psychology | 社会心理学（成立） |
| 2 | 296 | Self-Consistent Equations (Kohn-Sham) | 密度泛函理论（成立） |
| 167 | 174 | National Cholesterol Education Program | 临床指南 / 激素替代（成立） |

**社区 8 是混的**：GLOBOCAN（癌症统计）与 BWA（序列比对）被同一批"癌症基因组"论文桥接在一起。
这说明引用图上的社区 ≠ 主题标签——跨领域方法论文会把两个圈子连起来。文档里如实写，
不宣称"自动得到学科分类"。

## 落地

| 位置 | 内容 |
|---|---|
| `app/cluster.py` | `louvain()` 纯函数 + `build()` 落 `work_cluster(wid, cluster_id, size)` |
| `GET /clusters/top` | 最大社区 + 每社区代表论文（按库内被引排序） |
| `GET /work/{wid}` | 多一个 `cluster`：`{cluster_id, size, papers[]}`（同社区其他论文） |
| 前端论文页 | 标题下显示「研究社区 #159（共 121 篇互相引用的论文）」 |
| 快照 | `work_cluster` 1,200 行，clone 后可复现 |

## 测试

`tests/test_cluster.py`（7 项）：

- 桥边不合并两个团（Louvain）✓
- **同图标签传播会合并**（把对照实现的失败也钉成测试，防止有人"优化"回去）
- 断开的两团分开
- 孤立点自成一类
- 空图 / 单点
- 确定性（同输入同输出，否则社区 id 每次重建都变）
- 边里出现未知节点时忽略

全量 **118 项**通过。

## 遗留

1. **只跑了 Louvain 的第一阶段**（局部移动），没做聚合迭代，社区粒度偏细（3,406 个）；
2. **没有层次结构**：拿不到"大社区里的小圈子"；
3. **社区 id 不稳定**：新增论文后重跑，id 会变（用"社区内最小 wid"归一，但成员变了 id 仍可能变）；
4. 社区 8 那类"被桥接"的混合社区没有检测机制。
