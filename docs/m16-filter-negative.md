# M16：主题重叠过滤——两次尝试都失败，不采用

M15 抽样发现 7.5% 的网络背书是"C 类"（企业/无关领域）。最直接的想法是加一条
"候选人主题必须与种子主题重叠"的过滤。**试了两版，都不成立。**

## 第一版：种子 signature = 合作者高频主题 top-30

结果：

```
保留 238 / 降级 0
签名示例: Anesthesia, Asthma, Biochemistry, Biology, COPD, Cancer, Chemistry...
```

失败原因：签名里全是 `Biology` / `Chemistry` / `Computer science` / `Cancer` 这类**通用概念**，
几乎每个人都"重叠"，过滤器形同虚设。

## 第二版：只保留"有区分度"的主题

约束：在合作者中出现 ≥3 次，**且**全局出现率 < 15%。

结果：

```
保留 229 / 降级 9
降级的人：Ching Li Chai-Coetzer（睡眠呼吸暂停）、Nick A. Antic（呼吸暂停）、
          Daniel Queiróz（内分泌）、Jingrong Shi（流行病学）、
          Angela Stewart（环境健康/儿科）、Huizhao Liao（Meta 分析/睡眠）...
```

**两个方向都错**：

1. **误伤**：降级的 9 个人绝大多数是正经医学研究者——只是子领域（睡眠、内分泌、流行病学）
   和种子（呼吸/肿瘤）不完全重合。他们被挡掉是错的。
2. **漏放**：M15 抽到的 3 个 C 类（企业、食品科学、环境监测）**一个都没被降级**——
   因为它们身上挂着 `Chemistry` / `Medicine` 这类仍然留在签名里的词。

## 为什么不采用

| 方案 | 结果 |
|---|---|
| 不加过滤 | 7.5% 噪声，但**可筛选**（`endorse=network`）、有标记 |
| 加主题过滤 | 换掉 3 个真错误，误杀 9 个正常人（净损失） |

在"少 9 个好专家"和"多 3 个可疑专家（但有标记可筛）"之间，选后者。

## 根因

OpenAlex 的 `x_concepts` 是**粗粒度概念**（Biology / Chemistry / Medicine 这种），
不能区分"呼吸内科"和"食品科学"；而机构字段里企业、监测站、大学混在一起，
也没有可靠的类型标记。

**结论：在这个数据上，领域相关性无法用主题重叠自动判定。**
要么人工复核这 238 人（规模可接受），要么接受噪声 + 保留可筛标记。

## 已做的补偿

- `endorse=network` 筛选 + 卡片橙色徽章（M13）；
- `/health/trust` 监控占比（M14）；
- 人工抽样 40 条给出精度区间 77.5% [62.5%, 87.7%]（M15）。

这三件事合起来，比一个不可靠的自动过滤器更有用。
