# M15：校准"网络背书 ≤5%"阈值 + 定时健康检查

## A. 抽样校准

5% 这个上限原本是我拍的（依据：42% 明显失控、2.8% 看起来合理）。这次抽 **40 / 238** 位网络背书的专家人工标注。

标注口径（只看元数据，无法核实身份）：

| 等级 | 判据 |
|---|---|
| A 真专家 | 医院/大学机构 + 主题落在医学/呼吸/肿瘤等 + 作品数合理 |
| B 存疑 | 缺机构，或机构/主题部分偏离，但仍有医学产出 |
| C 不像 | 企业或完全无关领域（食品科学、环境监测） |

### 结果

| 等级 | 人数 | 占比 |
|---|---|---|
| A 真专家 | **31** | 77.5% |
| B 存疑 | 6 | 15.0% |
| C 不像 | 3 | 7.5% |

Wilson 95% 置信区间：

- A 的比例：**77.5%**，CI **[62.5%, 87.7%]**
- A+B（至少学术相关）：**92.5%**，CI **[80.1%, 97.4%]**

### C 类（该被拦住的）三个样本

```
pid=37686  Ruibo Huang      Kurabo Industries Ltd.（日本企业） 作品 12  Asthma
pid=37394  Yubo Ou          Guangdong Environmental Monitoring  作品 15  环境科学/气象
pid=37843  Peng-Xiao Chen   Henan University of Technology      作品 18  食品科学
```

共同点：**机构与企业/非医学领域 + 与种子（呼吸医学）主题不重叠**，只是恰好共著过 ≥2 篇。

### 结论

1. 网络背书的精度约 **78%（严格）/ 93%（宽松）**，不是"高可信"，但也不是"随便灌人"；
2. 按 2.8%（238 人）算，其中 **约 18~52 人** 质量存疑；若把上限放到 5%（424 人），存疑人数会到 30~90；
3. **5% 上限可以保留**，但建议再加一条硬约束：

> 网络背书要求：本人主题与种子专家的主题**至少重叠 1 个**。

这条能精确挡掉上面 3 个 C 类样本（它们与种子的主题集合没有交集），实现成本低，
但需要 `person_org`/`edges` 记住"是谁背书的"——我们的 evidence 里已经存了
`source=network_of:<pid>`，可以据此回查种子主题。**这条还没做**，列为待办。

## B. 定时健康检查

### 实现

`app/health_watch.py`：

```bash
python -m app.health_watch --once            # 跑一次
python -m app.health_watch --interval 21600  # 每 6 小时（默认）
```

- 每次结果追加到 `logs/health.jsonl`（JSONL，一行一次）；
- 不通过时写 `logs/health_ALERT.txt`（内容含哪项、当前值、限制、修复建议），恢复后自动删除；
- 单次异常不会让守护进程退出（`try/except` 包住循环体）。

启动方式（这台机器没有 sudo，所以不用 cron）：

```bash
setsid nohup .venv/bin/python -m app.health_watch --interval 21600 \
  > logs/health_daemon.log 2>&1 < /dev/null &
echo $! > logs/health.pid
```

**踩了两次坑**：判断"是否已在运行"时用 `ps | grep "[p]ython -m app.health_watch"`，
结果匹配到了**脚本自身**（脚本文本里就含有这行命令），永远判定"已在运行"。
最后改用 **pidfile + `kill -0`** 才可靠。

### 接口

`GET /health/history?limit=20` → 最近 N 次记录 + 当前告警文本（没有则 null）。

### 现状

```
守护进程 pid 997382 存活（每 6 小时）
logs/health.jsonl 已有 2 条记录，最新 ok=true
/health/trust 六项全绿（网络背书 2.80%）
```

## 还有效的两个限制

1. **A 的标注是我一个人做的**，只依据元数据（姓名/机构/主题/作品数），无法核实身份——
   所以 77.5% 是"看起来像专家"的比例，不是真正的精确率。
2. **主题重叠过滤没做**，这是把 7.5% 的 C 类真正挡住的最直接办法。
