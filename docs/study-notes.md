# `study` 分支说明

这个分支是**学习用**的：在 `main` 的代码上加了逐段中文注释（检索流程、Agent 主循环、
工具派发、记忆写入等），便于对照阅读。

约定：

- **`main` 保持干净**：只放正式代码，不带个人学习批注；
- **`study` 只加注释，不改逻辑**：任何代码改动都应回到 `main` 做；
- 每次 `main` 更新后，用 `git merge main` 把新代码带进来，再补注释；
- `study` 不用于部署，也不合并回 `main`。

> 提醒：注释也属于代码——如果注释里的函数签名/行为已经过时，会误导读者。
> 所以在 `main` 有改动后，记得检查对应注释是否还成立。
