# M33：国家字段补到 97%，以及一次"差点把数据搞脏"的事故

## 目标

`people.country` 之前基本是空的。上一轮补到 82%（38,980/47,569），这一轮要做到接近全量，
并且**能说清每个值是怎么来的**。

## 第一版：先抓 `last_known_institutions`

OpenAlex 的作者记录里，`last_known_institutions[].country_code` 是最直接的来源，
而且它和我们库里存的 `last_inst` 同源——不会出现"机构是 A 国、国家标成 B 国"。

跑完：8,589 人取不到（多为老论文/低活跃作者，这个字段为空）。

## 第二版：用 `affiliations` 兜底 —— **这里翻车了**

`affiliations` 是历史任职列表，通常还留着带 `country_code` 的记录。于是加了回退：
取"年份最大"的那段任职所属机构的国家。

跑完覆盖率跳到 **97%**，看起来很好。**但我随手抽查了 6 个 `country=CN` 的人**：

```
Da Jiang        | University of Manchester      ← 英国
Jue Ruan        | Boston College                ← 美国
Tianjing Li     | Johns Hopkins University      ← 美国
Feiwu Chen      | University of Science and Technology Beijing  ← 中国 ✓
```

6 个里 3 个明显错了。再统计：CN 的 10,311 人里，机构名含中国关键词的只有 35%。

### 根因

`affiliations` 里有些记录的 `years` 是**空数组**。我当时的写法是：

```python
y = max(years) if years else 0     # ← 空数组时 y=0
```

于是所有"没有年份"的任职记录都用 `0` 参与比较，而 `0` 不会大于已记录的年份，
但如果**所有**记录都没有年份，`best_year` 就一直是 `-1`，谁先出现谁赢——
等于随机挑了一段几十年前的经历当"现任"。

**这不是精度问题，是逻辑漏洞。** 而且它不报错、不告警，覆盖率还变高了。

## 第三版：带来源标记重算

修法有三条：

**1. 没有年份的历史任职，直接放弃**

```python
years = [y for y in (aff.get("years") or []) if isinstance(y, int)]
if not cc or not years:
    continue        # 不知道是不是"最近"的，就不要
```

**2. 加 `country_src` 列，记录来源**

| 来源 | 含义 | 数量 |
|---|---|---|
| `author` | 现任机构的 `country_code`（与 last_inst 同源） | 39,062 |
| `affiliation` | 历史任职里**带年份**的最近一段 | 7,425 |
| `institution` | 机构多数国家（≥80% 且样本 ≥3） | 0 |
| `none` | 三个来源都没有 | 1,082 |

没有这一列，事后就分不清"作者自报"和"历史推断"，也没法只信任其中一部分。

**3. 机构国家只由 `author` 来源的人投票**

上一版用"所有人"的多数来定机构国家，等于拿推断出来的国家再去推别人，
**一次错误会被放大成一片**。现在机构国家重算，只统计 `country_src='author'` 的人。

## 结果

| 指标 | 修前（第二版） | 修后（第三版） |
|---|---|---|
| 有国家 | 46,487 / 47,569（97%） | 46,487 / 47,569（97%） |
| 已发布有国家 | 8,488 / 8,490（99%） | 8,488 / 8,490（99%） |
| CN 人数 | 10,311 | 10,295 |
| **CN 里机构明显在英美的** | 抽样 3/6（~50%） | **38 人（0.4%）** |
| 机构有国家 | 4,319（掺了推断） | 4,012（只由 author 投票） |

覆盖率没变，但**数据的可信度完全不同**——这就是来源标记的价值。

剩余 1,082 人（2.3%）三个来源都没有：他们的 OpenAlex 记录里既无现任机构、
也无带年份的历史任职。诚实地说，这批人就是补不上。

## 这一轮的教训

1. **覆盖率是个会骗人的指标**。从 82% 到 97% 只花了几分钟，但一半是错的；
2. **"缺失值兜底"必须比"主来源"更严格，不是更宽松**。我当时的直觉是"多填一点总比空着好"，
   方向反了——空着只是不知道，填错是制造假数据；
3. **没有来源标记的数据集，无法事后纠错**。加一列 `country_src` 的成本，远低于重新判断
   四万条数据的成本。

## 测试

`tests/test_country.py`（5 项）把规则固定下来：

- 现任机构优先；
- 历史任职**必须有年份**，否则返回 `None`；
- 多段任职取年份最大；
- 没有 `country_code` 的记录不算数；
- 空记录不抛异常。

## 遗留

1. `affiliation` 来源（7,425 人）仍可能有少量"最近一段任职在海外、但人已回国"的错配，
   前端没有区分展示——若要用于统计排名，建议只取 `country_src='author'`；
2. 机构国家从 4,319 降到 4,012，是因为只统计可信来源，不是数据丢了；
3. 缺国家的 1,082 人暂时无解，需要人工或第三方机构库。
