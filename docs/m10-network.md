某学术图谱的 `trajectory_profile.collaboration_tracks` 有 11 条，但**合作对象全是机构/平台，不是人**：

| 8.7 | 广东省呼吸与健康学会 | 学术活动与科普 | org |

所以如果只做"人—人合作网络"，他的节点会是**孤立的**（我们原来的合作者数就是 0）。
只做"机构网络"又看不到同行。因此做了**两层**。

## 两层是什么

### 第一层：人—人（共著）

导入的 7 篇论文原来没有边（边只在主库采集时统一生成）。补建后：

```
新建 53 条共著边，加权 145 条（已有的边累加权重）
527 现在有 11 位共著者
```

抽样（都是广州医科大学附属第一医院）：

```
Wei-jie Guan / Wenhua Liang / Chun-Quan Ou / Chunliang Lei / Chunli Tang ...
```

口径与主库一致：只连前 12 位作者（100 作者的大协作论文会产生 4,950 条边）。

### 第二层：人—组织

新表：

```sql
orgs(oid, ext_id, name, name_zh, kind)
person_org(pid, oid, relation, weight, first_year, latest_year)
```

`kind` 由外部 id 前缀推断：`platform-*` → 平台，`inst-*` → 机构，`org-*` → 组织，`partner-*` → 合作方。

## 接口与前端

`GET /graph/{pid}` 现在返回三段：

```json
{
  "nodes": [ {pid, name, works_count, community, ...} ],   // 人
  "edges": [ {a, b, weight} ],                             // 共著
  "orgs":  [ {oid, name_zh, kind, relation, weight} ]       // 机构/平台
}
```

前端图谱：

- 人 = 圆形，颜色按机构/社区/影响力；
- **机构/平台 = 金色圆角方块，用虚线连到中心人物**，悬停显示 `类型 · 关系 · 权重`；
- 点击只对人节点生效（组织节点没有画像页）；
- 图例多一项"机构/平台（11）"。

专家墙卡片：

```
钟南山 / Nanshan Zhong   10 篇 · 被引 30,248
[平台/机构 11 · 看网络]  ← 点它直接跳到该专家的网络图
```

```
/experts?source=huafu → 钟南山，works 10，平台 11
单测 10 个通过
```

## 遗留

1. **机构节点还没有反向聚合**：点"广州实验室"看不到还有哪些专家也属于它。
   要做的话需要 `/graph/org/{oid}`（列出 `person_org` 里该机构的人）。
2. **某学术图谱只给了 1 个人的关系**：其余 482 人如果也导进来，机构节点会自动复用（`ext_id` 唯一），
   那样"广州实验室"就会连出真实的一群人，图谱才有意义。
3. **权重口径不同**：某学术图谱的 weight（9.8/9.6…）是人工评估的关系强度，
   我们的共著边 weight 是共同论文数，两者画在同一个scale 上不可比——所以机构边用虚线 + 固定粗细。

## 自查修正（用户："你自己看看构建的这张网"）

我把上一版拆开检查，发现**三个硬伤，全部是我造成的**：

| # | 问题 | 证据 |
|---|---|---|
| 1 | 导入的 7 篇论文变成**单作者论文** | `work_authors` 里每篇只有他 1 人 |
| 2 | 合作者只有 **11 人**，而他论文里出现 **70 人** | 覆盖率 11/70 = **16%** |
| 3 | 原因在我自己写的建边规则 | 主库建边只连"前 12 位作者"，他的 COVID 论文有 35/44/37 位作者，**他不在前 12** |

结论：上一版那张"11 位合作者"的网是**假的**，看起来完整其实只覆盖了六分之一。

### 修法

1. **按 DOI 回 OpenAlex 补真实作者**（`app/enrich_works.py`）
   7 篇有 DOI 的论文逐篇取 `authorships`，补人、补 `work_authors`。
   结果：作者数从 `1/1/1/1/1/1/1` 变成 `12/12/8/12/2`（另 2 篇无 DOI 仍为 1）。
2. **改"全对全"为"以他为中心"的星形边**
   44 位作者全对全是 946 条边/篇，没有意义。改成"中心 ↔ 同篇每位作者"，权重=共同论文数。
3. **图上截断但显示总数**
   合作者 111 人全画看不清，默认取共著权重前 60，提示写成
   `网络：61 位同行（已显示前 60 位，共 111 位）+ 11 个机构/平台`。

### 修正后的实测

```
/graph/527?depth=1                        → 节点 61（截断），共 112
/graph/527?depth=1&max_collaborators=200  → 节点 112
他的 10 篇论文作者数：12 / 12 / 8 / 12 / 2 / 1 / 1 / 35 / 45 / 37
共著者：111 人（其中 7 位 published，其余 pending）
共同论文数前 3：Wei-jie Guan(3)、Wenhua Liang(3)、Chun-Quan Ou(3)
```

### 仍未解决

1. **2 篇无 DOI 的论文仍是单作者**（某学术图谱记录里没给 DOI，我无法凭空补）；
2. **权重大多是 1**：他只有 10 篇论文在库里，真实合作强度（几十篇共同论文）体现不出来；
3. **机构节点只连他一个人**：`person_org` 只有他 11 条，机构反查（`/graph/org/{oid}`）还没做。

**教训**：上一版我只看"接口 200、节点数不为 0"就宣布完成，没检查**覆盖率**。
这次的检查口径是"论文里出现的作者数 vs 变成共著者的人数"——这个比值才说明网络全不全。
