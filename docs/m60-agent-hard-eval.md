# M60：Agent 难例评测（把饱和指标撑开）

## 为什么做

原有 14 条用例通过率 100%——**饱和指标没有判别力**。RSI 的闸门建在饱和指标上，
只能拦回归，拦不住"优化了错误的东西"。

Claude 的建议：**加难度，不是加数量**。14 条简单用例扩到 60 条仍然是简单用例。

## 12 条难例（`eval/agent_hard.jsonl`）

| 类别 | 用例 | 期望 |
|---|---|---|
| 不存在的人/主题 | 王小明（量子计算）、张伟明、quantum gravity phenology、NFT 艺术市场、诺贝尔奖人数 | 必须拒答 |
| 跨人对比/关系 | 钟南山 vs 李兰娟谁被引高；两人合作过吗 | 必须同时出现两人 |
| 歧义/空上下文 | "推荐几个专家"（无任何上下文） | 必须追问 |
| 记忆冲突/约束 | 改做阿尔茨海默；只找中国的专家 | 新事实覆盖旧事实；约束生效 |
| 多轮指代 | "钟南山的合作者里谁被引最高" → "那李兰娟呢" | 第二轮靠上下文 |
| 多条件 | 近五年 + 被引最高 + 中国 + 呼吸科 | 条件叠加 |

判定全部是机械的：`refused` / `must_any` / `must_not` / `tools_any` / `items_country_any`。

## 基线：9/12，暴露三个真问题

1. **记忆能答的问题被"无证据守卫"拒答**：问"我现在研究什么方向？"时记忆里有
   `topic=阿尔茨海默`，但没有工具条目 → 守卫强制返回"知识库里没有找到"。
2. **约束抽取漏词**："我只找中国的专家" 里 `只找` 不在规则里，`country` 也没有进入
   `hint`，所以记忆约束完全不生效。
3. **拒答判定不稳**：同一句"专家库里没有研究 X 的专家"，`refused` 时真时假（2/3）。

## 修复

| 问题 | 修复 |
|---|---|
| 记忆问题被拒答 | 新增 `_memory_answer()`：第一人称 + 研究/方向/领域类问题时，直接用记忆回答，不走工具 |
| 约束不生效 | `memory_extract` 增加国家约束正则（只找/只考虑 + 国家名）→ `key=country`；`build_hint` 暴露 `country`；`apply_to_parsed` 已有填空逻辑 |
| 空上下文硬推 | 新增 `_clarify()`：纯"推荐几个专家"且无记忆时，追问领域 |
| 拒答抖动 | 否定词窗口 18→40 字符，并加入 `命中/核心/结果`；顺带修 `refused` 漏判 |

## 结果

| 指标 | 基线 | 修复后 |
|---|---|---|
| 难例 12 条 | 9/12（75%） | **12/12** |
| 常规 14 条 | — | 14/14（无回归） |
| 拒答稳定性 | 2/3 | **3/3** |

## 已知局限

- 难例仍只有 12 条，置信区间很宽（12/12 的 95% 下界约 76%）；
- "记忆使用率 0%" 是度量口径问题：记忆题现在走 `_memory_answer` 短路，不调工具，
  指标统计不到，需要单独计数；
- 空上下文追问只覆盖"推荐几个专家"这类固定形态，其他模糊表达仍可能硬推。
