# M2 报告：混合检索与评测（含一次"评测本身有偏"的自我纠正）

## 做了什么

1. **向量通道**：bge-small-en-v1.5（transformers 直载，CLS + L2），给 4,814 位发布专家和 8,000 篇论文建嵌入
   - 人物文档 = 姓名 + 机构 + 8 个主题 + 5 篇代表作标题
   - 建向量耗时：works 375s、people 141s
2. **融合**：RRF（k=2 / k=60）与 DBSF 两路融合
3. **gold set 两套**（真值都来自结构化字段，不靠主观标注）

看起来"权威性先验"是巨大胜利（+74%）。**但这是假的**——见下。

## 自我纠正：先验的收益大部分是标签泄漏

第一套 gold 的 institution/topic 真值是"按被引排序的前 5 人"，
而"权威性先验"正是按被引重排——**等于让模型去拟合标签的构造方式**。

于是做了第二套真值：该机构/主题下**随机抽 8 人**（与被引无关）：

| 配置 | R@10 | nDCG@10 |
|---|---|---|
| bm25 | **0.263** | **0.243** |
| dense | 0.068 | 0.065 |
| rrf_k60 | 0.203 | 0.199 |
| bm25 + λ=0.5 | 0.265 | 0.245 |
| bm25 + λ=2 | 0.258 | 0.243 |
| **bm25 + λ=8** | 0.215 | **0.214（比不用先验更差）** |

**结论：权威性先验在"不按被引排序"的真值上没有收益，λ 大时反而伤害召回。不采用。**

这条比"M2 提升了 40%"更值钱：它说明我有能力发现自己的评测在骗自己。

## 其他结论

1. **BM25 明显强于向量通道**（0.243 vs 0.065 on gold#2）。
   原因是数据形态：人物文档是"姓名+机构+主题"的实体卡片，查询也多是实体词，
   词面匹配天然占优；而 bge-small-en 是通用模型，对 OpenAlex 概念名不敏感。
2. **融合没有赢过更好的单路**（gold#2：RRF 0.199 < BM25 0.243）。
   按 Qdrant 调优指南的建议——"先确认融合能赢过更强的单路，否则就停在这里"——**默认不启用融合**。
3. **collaborator 类查询所有配置都 ≈ 0**：这类问题需要**图遍历**（谁和谁合作），
   不是检索问题。这正好是 M4 Agent 里 `collaborators` 工具的动机。

## 对 M4 的影响

既然检索层已经到顶（BM25 + 无融合），Agent 的价值要落在**检索做不到的事**上：

| 查询类型 | 现状 | 由谁解决 |
|---|---|---|
| 人名/机构/主题 | BM25 nDCG 0.243~1.0 | 检索（够用） |
| 合作关系 | ≈0 | **图工具**（递归 CTE） |
| 多跳比较（"谁更适合做 X 的审稿人"） | 无 | **Agent 规划 + 多工具** |
| "资料不足" 判断 | 无 | **拒答策略**（复用医药项目的三档闸门思路） |

## 第四个发现：FTS5 默认不做词干化，英文语料必须换 porter

现象：`/search?mode=bm25&q=graph neural networks` 返回空，而单词分别命中 169/246/17。
原因：OpenAlex 主题名是 **"Graph Neural Network"（单数）**，查询用的是复数，FTS5 的
`unicode61` 不做词干化，`"networks"` 与 `"network"` 是两个不同的 token。

改成 `tokenize='porter unicode61'` 后：

| | 改前 | 改后 |
|---|---|---|
| `"network"` 命中 | 17 | **705** |
| `"graph" AND "neural" AND "network"` | 0 | **5** |

整体指标变化很小（gold#2 nDCG 0.243 → 0.242），因为只影响少数查询；
但"主题类查询返回空"这种**硬失败**被修掉了——比小数波动重要。

## M2 最终结论

| 结论 | 证据 |
|---|---|
| BM25 是当前最强单路 | gold#2 nDCG 0.242 vs dense 0.065 |
| 融合不启用 | RRF/DBSF 都没赢过更强的单路（0.196/0.103 < 0.242） |
| 权威性先验被证伪 | 在"随机真值"上 λ=8 反而降到 0.214 |
| collaborator 需要图工具 | 所有检索配置 ≈ 0 |
| 英文语料要 porter | 修掉主题查询硬失败 |
| 查询需要松弛 | AND 无结果时退到 OR：`graph neural networks` 从空集变为可返回候选 |
