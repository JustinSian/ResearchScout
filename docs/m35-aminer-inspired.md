# M35：抄 AMiner 的四个设计（引用链、三层权重、可追溯、降级）

读了 AMiner 开放平台的 28 个接口后，有四个设计值得搬过来。这一轮落地了前三个。

## 1. 引用关系（对标 `paper/relation`）

**我们原来只有被引计数**（`works.cites`），没有"引用了谁"，所以做不了引用链。

新增 `work_refs` 表 + `app/fetch_refs.py`：从 OpenAlex 的 `referenced_works` 抓，
50 篇一批，把被引论文的 openalex id 落库，并尝试映射回库内（`ref_wid`）。

```
11,097 篇 × 引用关系 → 一键得到：
  GET /work/{wid}/citations   它引用了谁（库内展开标题，库外只给 id）
  GET /work/{wid}/cited-by    库内谁引用了它
  GET /citations/top          库内被引最多（按库内边计，不是 OpenAlex 总被引）
  对话："这篇论文引用了谁：<标题>"
```

**诚实边界**：库外引用只保留 openalex id，不编造标题与作者。

实测（全量）：**10,931 篇 / 564,433 条引用 / 库内边 30,101（链回率 5.3%）**。
链回率不高——语料只收 11k 篇，引用大多指向库外；这比"假装能展开"要好。

## 2. 三层主题权重（对标 `paper/qa/search` 的 topic_high/middle/low）

AMiner 允许把关键词分成三层：必含、加分、可选。我们的等价物：

| 层 | 我们的实现 |
|---|---|
| **high**（必含） | 主题词翻成英文后进 FTS，必须命中任意一个 |
| **middle**（硬条件） | 国家 / 机构类型 / 机构名 / 被引门槛，SQL 过滤 |
| **low**（加分） | 概念命中数 + **论文标题命中数**，用于同分排序 |

一开始只算了概念命中数，结果**所有人都是 1 分**——OpenAlex 的 topics 太粗
（"Medicine" 这种），同义词基本不共现，等于没排序。加上论文标题命中后才分得开。

效果（`中国的呼吸科专家`）：

| 排序方式 | 前三位 |
|---|---|
| 只按被引（旧） | Huanming Yang（21.9 万被引，基因组学）· Kwok-Yung Yuen · George F. Gao |
| 加权（新） | **周玉民（280 篇，主题命中 25）· 陈荣昌（180 篇）· Zhishan Deng（111 篇）** |

旧答案里前三位都不是呼吸科临床医生；新答案里陈荣昌、周玉民都是国内 COPD 领域的
一线临床研究者。**这才是"找专家"该有的答案。**

## 3. 可追溯（对标 `source_api_chain`）

`/chat` 现在返回：

```json
{"route": "kb", "agents": ["kb"], "sources": ["kb"], "elapsed_ms": 33.2, ...}
```

AMiner 把"这条结果由哪些 API 组合得到"作为一等公民；我们至少让调用方知道
**走了哪条路、花了多久**，而不是只给一段文字。

## 4. 降级链（对标 `paper_qa → paper_search_pro`）

我们已有：`kb → web`（AnySearch）、`task → kb → web`、`facet 0 结果 → 放宽被引门槛`。
这一轮没改，只记录为"已对齐"。

## 没抄的部分（以及为什么）

| AMiner 有 | 我们不做 | 原因 |
|---|---|---|
| `person/figure`（教育/工作/荣誉结构化） | 不做 | OpenAlex 没有教育经历，编不出来 |
| `project/person`（科研项目、资助金额） | 不做 | 需要基金委/NSFC 数据源，成本高于收益 |
| `patent/*` | 不做 | 与本项目"学术专家"定位无关 |
| 按次计费（¥0.01~¥3） | 不做 | 我们是自建库，成本模型不同；但 `/chat` 的 `elapsed_ms` 是最小可观测单元 |

## 验收

| 项 | 结果 |
|---|---|
| 引用接口 | `wid=39`：引用 13 篇 / 库内 2 篇 / 被库内 42 篇引用 ✓ |
| 对话引用链 | "这篇论文引用了谁：…" → 给出引用数、库内数、库外 id ✓ |
| 加权排序 | 呼吸科问题从基因组学家变成呼吸科临床医生 ✓ |
| 可追溯 | `route/agents/sources/elapsed_ms` 全部返回 ✓ |
| 测试 | 新增 5 项（引用查询解析）；全量待跑 |

## 遗留

1. **库内引用链回率仅 5.3%**：语料只收了 11k 篇，引用大多指向库外；
2. **`work_refs` 只覆盖已抓取的论文**（后台任务进行中），未抓到的论文调用会返回 0；
3. **加权排序目前只用概念+标题**，没有像 AMiner 那样允许用户手工指定三层关键词——
   如果要做，可以在 `/search` 增加 `topic_high/low` 参数。
