# M24：前端打磨（对比模式 + 图谱联动 + 任务历史）

## 三个新增

### 1. 对比模式

尽调页加了「对比模式」勾选框和第二个输入框。勾上后只需要填两个人名：

```
第一位：钟南山
第二位：李兰娟
→ 自动拼成："比较钟南山和李兰娟近五年的研究方向差异"
```

好处是普通用户不用记住句式；后端意图识别本来就需要"比较 + 两个人名"，这个入口正好对上。

### 2. 图谱联动

任务跑完后，顶部出现一排按钮：

```
[画像：钟南山] [画像：何建行] [合作链：钟南山 ↔ 何建行] [钟南山的合作网络]
```

点「合作链」会切到图谱页并进入**两人路径模式**，自动填充两个 pid 并重新渲染。

后端为此在 `/task` 与 `/task/{tid}` 的返回里加了 `people`：

```json
"people": [{"pid": 527, "name": "Nanshan Zhong", "name_zh": "钟南山"},
           {"pid": 498, "name": "Jianxing He",   "name_zh": "何建行"}]
```

### 3. 最近任务

「最近任务」按钮列出最近的 8 个任务（含失败状态），点任意一条回看：
步骤流、报告、产物链接、审计成本都会重新渲染。

## 实测

```
POST /task（对比模式生成的问句）
  tid 28 | people: [('钟南山', 527), ('何建行', 498)]

GET /task/28
  people: [('钟南山', 527), ('何建行', 498)]

GET /graph/path?a=527&b=498
  1 跳 ['Jianxing He', 'Nanshan Zhong']
```

路径接口本来就有（双向 BFS），之前只是**没有入口**——从尽调结论点不到图谱。
这次把"结论 → 证据 → 关系"打通了：报告说两人是直接合作者，
点一下就能看到他们之间的边。

## 一个仍然不完美的地方

`openPath` 是"点模式按钮 + 点导航 + 调 buildGraph"三步拼接。
如果图谱页的模式切换本身已经触发过一次 buildGraph，这里会**渲染两遍**。
视觉上看不出来，但双重网络请求是浪费。正确做法是让模式切换幂等，
或者暴露一个 `setGraphMode(mode, a, b)` 接口——没做，记在这里。
